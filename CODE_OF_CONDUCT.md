# Código de conducta

Este proyecto busca mantener un espacio respetuoso y útil para todas las personas que quieran colaborar.

Se espera una comunicación cordial, críticas centradas en el código y respeto por distintos niveles de experiencia. No se aceptan insultos, acoso, discriminación, publicación de información privada ni conductas que dificulten la participación de otras personas.

Los comentarios o contribuciones que no respeten estas pautas podrán ser editados, rechazados o eliminados. Los casos sensibles pueden informarse de manera privada al responsable del repositorio.
