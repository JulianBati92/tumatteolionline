# Historial de cambios

Los cambios importantes del proyecto se documentan en este archivo.

## Próxima versión

### Seguridad

- Los precios del checkout se resuelven desde un catálogo controlado por el servidor.
- El navegador deja de escribir pedidos directamente en Firestore.
- Se validan productos, cantidades y datos de contacto antes de crear la sesión de pago.

### Mantenimiento

- Se incorporan licencia, política de seguridad y guía para contribuir.
- Se agregan comprobaciones automáticas de sintaxis y dependencias.
