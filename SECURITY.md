# Política de seguridad

## Reportar una vulnerabilidad

No publiques vulnerabilidades, credenciales o datos personales en un issue. Utilizá la opción **Report a vulnerability** de la pestaña Security del repositorio.

Incluí una descripción clara, pasos para reproducir el problema y el impacto posible. Voy a confirmar la recepción del reporte y mantener la información actualizada mientras se analiza una solución.

## Alcance

Se consideran especialmente importantes los problemas relacionados con:

- manipulación de precios o cantidades;
- acceso indebido a pedidos o datos personales;
- exposición de credenciales de Firebase o Stripe;
- abuso de Firebase Functions;
- dependencias vulnerables.

No incluyas información de pago real en las pruebas. Usá siempre el modo de prueba de Stripe y los emuladores de Firebase.
